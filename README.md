# AI Interview Preparation Platform

An AI-powered web app that turns a **job description** and your **resume** into a personalised interview-prep plan. It generates technical and behavioural questions (with the interviewer's intention and a model answer), a match score, skill gaps, a day-by-day preparation road map, and even a job-tailored resume PDF.

Built with the **MERN** stack (MongoDB, Express, React, Node.js) and **Google Gemini**.

## Features

- **User authentication**: register, login and logout with JWT stored in an HTTP cookie. Logged-out tokens are blacklisted.
- **Personalised interview report** generated by Gemini from the job description, resume (PDF) and/or a short self-description.
- **Match score** (0–100) showing how well your profile fits the role.
- **Technical questions** (8–10), each with the interviewer's intention and a detailed model answer.
- **Behavioural questions** (6–8) with STAR-method guidance.
- **Skill gaps** with low / medium / high severity.
- **Preparation road map**: a day-wise plan (minimum 5 days) with concrete tasks.
- **Download Resume**: Gemini writes an ATS-friendly resume tailored to the job, rendered to PDF with Puppeteer.
- **Report history**: every generated report is saved and can be reopened later.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or newer
- A [MongoDB Atlas](https://www.mongodb.com/atlas) cluster (or a local MongoDB instance)
- A [Google Gemini API key](https://aistudio.google.com/apikey)

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd interview-ai-yt
```

### 2. Set up the backend

```bash
cd Backend
npm install
```

Create a file named `.env` inside the `Backend` folder:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=a_long_random_secret_string
GOOGLE_GENAI_API_KEY=your_gemini_api_key
```

Start the server:

```bash
npm run dev
```

You should see:

```
Server is running on port 3000
Connected to Database
```

> **MongoDB Atlas tip:** if the server exits with "Failed to connect to MongoDB", add your current IP address under **Network Access** in Atlas and double-check the username and password in `MONGO_URI`. Special characters in the password must be URL-encoded.

### 3. Set up the frontend

Open a second terminal:

```bash
cd Frontend
npm install
npm run dev
```

Open **http://localhost:5173** in your browser.

> The frontend expects the API at `http://localhost:3000`, and the backend allows CORS from `http://localhost:5173`. Change these in `Backend/src/app.js` and the `baseURL` in `Frontend/src/features/*/services/*.api.js` if you use different ports.

## API Reference

Base URL: `http://localhost:3000`

### Auth: `/api/auth`

| Method | Endpoint | Access | Description |
| --- | --- | --- | --- |
| POST | `/register` | Public | Register a new user (`username`, `email`, `password`) |
| POST | `/login` | Public | Log in with `email` and `password` |
| GET | `/logout` | Public | Clear the cookie and blacklist the token |
| GET | `/get-me` | Private | Get the logged-in user's details |

### Interview: `/api/interview`

| Method | Endpoint | Access | Description |
| --- | --- | --- | --- |
| POST | `/` | Private | Generate a new report (multipart form: `jobDescription`, `selfDescription`, `resume` file) |
| GET | `/` | Private | List all of the user's reports |
| GET | `/report/:interviewId` | Private | Get one full report |
| POST | `/resume/pdf/:interviewReportId` | Private | Generate and download a tailored resume PDF |

## How It Works

1. The user logs in and pastes a job description, then uploads a resume or writes a short self-description.
2. The backend extracts the resume text with `pdf-parse`.
3. The text is sent to Gemini with a Zod-defined JSON schema, so the response always has the same structure (score, questions, skill gaps, plan). The output is validated before it is saved.
4. The report is stored in MongoDB and shown in the UI under **Technical Questions**, **Behavioural Questions** and **Road Map**.
5. **Download Resume** asks Gemini for tailored resume HTML and converts it to PDF with Puppeteer.

---

## Known Limitations

- Resume upload currently supports **PDF only**, with a **3 MB** limit enforced by the backend (the upload box text mentions DOCX and 5 MB).
- A report currently needs a resume file; generating from the self-description alone is not handled by the backend yet.
- The first Puppeteer run may download a Chromium build, so it can take a while.
- Report generation takes roughly 30 seconds because it depends on the Gemini API.
